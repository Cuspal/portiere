### Privacy posture summary
The **`offline=True` guarantee is the real control and it holds** — remote LLM
and remote embedding providers are rejected at config construction, and
`Project.__init__` / `concept_mapper` re-assert at runtime (verified earlier this
session). F-001/F-002 are therefore defense-in-depth gaps that only bite when a
user *opts out* of offline into a remote provider — at which point egress is
accepted. F-003/F-004 are scrubber-coverage gaps in the base (regex) install.
None is an S1: nothing escapes the machine under the documented/default posture.
